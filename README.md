# Devo Productions — Website

Static site for Devo Productions LLC (mobile DJ/MC, church sound consulting and training). No build step.
Hosted on Cloudflare Pages, deployed from this repo's `main` branch.

```
index.html            /          Home
services/index.html   /services
about/index.html      /about
gallery/index.html    /gallery
book/index.html       /book      Inquiry form (Web3Forms) + FAQ
links/index.html      /links     Link-in-bio page
img/  video/          Media
404.html              Not-found page
```
Each page carries its own CSS. The previous site is preserved on the branch `backup/pre-redesign-2026-10-13`.
